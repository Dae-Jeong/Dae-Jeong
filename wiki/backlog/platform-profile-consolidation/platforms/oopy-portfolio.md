# oopy 포트폴리오 — 2026-08-08 수집

로켓펀치·그룹바이·링크드인이 링크로 가리키는 대상. **6개 플랫폼 중 가장 정제된 서술이고, 다른 어디에도 없는 정보를 담고 있다.**

## 헤드라인

> **비즈니스의 가치를 코드로써 실현하는 엔지니어**

강점 3가지가 그룹바이 자기소개보다 훨씬 기술 중심이다.

1. **"좋은 설계가 좋은 서비스를 만든다"** — FastAPI/NestJS MSA 구축, Spring Boot DDD 설계, 비동기 시스템 개선(Celery→TaskIQ), JWT 멀티서비스 인증, CI/CD. "왜 이렇게 설계해야 하는가"를 고민
2. **개발자를 넘어 PM과 AI 엔지니어 경험으로 제품을 이해** — 테크 리드로 Centurion 3개 MSA 설계, PM으로 AI 이미지 생성 프로젝트 리드, 백엔드로 운영. 비즈니스 요구사항을 기술로 풀어내는 방법 체득
3. **문제 본질을 파악하고 빠르게 실행** — RabbitMQ 서비스 간 연동, SSE 실시간 알림, Azure 멀티 환경 배포 자동화. "재발 방지와 확장성을 고려한 해결책"

그룹바이 자기소개의 "새벽이든 주말이든 즉각 대응"류 헌신 서사가 여기엔 없다. **이쪽 톤이 더 낫다.**

## 기술 — 숙련도 2단계 구분

- 프레임워크: Spring Boot, FastAPI, NestJS
- DB: MySQL, PostgreSQL
- 클라우드: AWS, Azure
- 도구: Docker, Git, GitHub Actions

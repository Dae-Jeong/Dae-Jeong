# 리멤버 — 2026-08-08 수집

받은 제안 34건. 헤드헌터 노출이 가장 활발한 채널인데 **소개글이 3~4년 전 상태**다. 인적사항(생년·성별)은 채용 서비스 전용으로 등록돼 있으나 이 문서에 옮기지 않는다.

## 소개 (원문 — 방치된 버전)

첫 문장이 **"백엔드 개발자가 되고싶은 김대정입니다"**로 시작한다. 이후 프로젝트 4건을 "경험한 프로젝트"로 소개한다.

1. **Kidsly** — 아이 안면인식 비접촉 출결 시스템. 프로젝트 기획, 안면인식 AI 모델 개발, 출결 시스템 개발 담당. **프로젝트 팀장** 역할, 프론트 개발자 1명과 협업
2. **Eatup** — 음식 사진 기반 헬스케어. 프로젝트 관리와 음식물 인식 AI 모델 개발 담당. **PM** 역할
3. **Deep Scan** — 의류를 자체 하드웨어로 인식해 성분 분석. **서버 관리와 데이터 운영** 담당 *(다른 어느 플랫폼에도 없는 프로젝트)*
4. **Seller Canvas** — "**현재 진행하고 있는 프로젝트**"로 서술. 기획, API 서버 개발, 의류 사진 자동 배치 알고리즘 개발, 프로젝트 관리. PM 겸 백엔드 개발자. 「페이지 출력 방법」 특허 출원

이어서 **강점 4가지**를 서술한다.

1. 빠른 적응 능력 — "시작은 AI 엔지니어였으나 회사 요청으로 기획, 백엔드, 프론트, UX 디자인 역할을 수행"
2. 상황 판단 능력 — 대학 시절 창업 경험과 3개 프로젝트 관리 경험
3. 이성적·논리적 — "Seller Canvas 사업은 VC들에게서 투자를 받아 안정적으로 진행 중"
4. 창의적 — 경진대회 수상 이력, 특허 발명자 명시

마지막에 **단점 1가지**:

> "저는 확실한 제너럴리스트입니다. (…) **하나의 역할 만으로 프로젝트를 수행한 경험이 없습니다.** 단점을 개선하기 위해 백엔드 개발자의 역할을 전문적으로 담당하기 위해 사이드 프로젝트를 수행하고 있습니다. 동시에 **현재 진행중인 Seller Canvas 프로젝트가 마무리되면** 백엔드 개발자 단일 역할로 사내 프로젝트를 수행할 예정에 있습니다."

# 브라우저 반영 실행 지시서

너의 임무는 **아래 문안을 채용 플랫폼에 그대로 반영하고, 저장을 검증하는 것**이다.

## 절대 규칙

1. **문안을 한 글자도 수정하지 않는다.** 오탈자로 보여도 고치지 않는다. 문제가 있으면 중단하고 보고한다.
2. **지정된 필드 외에는 아무것도 건드리지 않는다.** 다른 버튼·설정·삭제 조작 금지.
3. **"화면에 보인다 ≠ 저장됐다."** 저장 후 반드시 페이지를 새로고침하고 텍스트가 남아 있는지 확인한다.
4. 같은 조작이 3회 실패하면 중단하고 실패 상태를 보고한다. 우회 방법을 창작하지 않는다.
5. 브라우저 도구(paseo MCP) 외의 작업 금지 — 파일 수정 금지, 셸 명령 금지(이 파일을 읽는 것 제외).

## 브라우저 조작 방법

paseo MCP의 browser 도구를 쓴다. 탭은 `browser_list_tabs`로 찾는다.

**한글 텍스트 입력은 반드시 이 방법을 쓴다** (`browser_type`은 한글이 입력되지 않는다):

```js
// browser_evaluate 안에서:
const ta = /* 대상 textarea 찾기 */;
ta.focus();
ta.setSelectionRange(0, ta.value.length);   // 기존 내용 전체 선택
document.execCommand('insertText', false, NEW_TEXT);  // 교체
```

저장 버튼은 텍스트로 찾아 클릭한다. 저장 후:

```js
// browser_reload 후 browser_evaluate로:
document.body.innerText.includes('검증용 문자열')  // true여야 성공
```

## 패키지 1 — 리멤버 소개 교체 (두 탭 모두)

### 진입

1. `browser_list_tabs`에서 URL에 `rememberapp.co.kr`이 포함된 탭을 찾는다.
   - 편집 페이지 탭(`profile.rememberapp.co.kr/edit...`)이 있으면 그 탭을 쓴다.
   - 없으면 아무 리멤버 탭에서 `https://profile.rememberapp.co.kr/edit?internal_path=myprofile_menu#introduction`으로 이동한다.
2. 소개(자기소개) 편집 영역을 찾는다. **탭이 2개다: `커넥트용`, `채용 서비스용`.** 둘 다 교체해야 한다.

### 교체할 문안 (두 탭 동일)

아래 텍스트 전체를 그대로 넣는다. 문단 사이 빈 줄을 유지한다.

```
AI 제품을 만드는 일만 4년째 하고 있습니다. 모델을 만들다 기획으로, 다시 백엔드로 자리를 옮겼고 지금은 만드는 일과 무엇을 왜 만들지 정하는 일을 함께 맡고 있습니다.

백엔드를 택한 건 AI가 구현을 점점 더 많이 맡게 될수록, 보안과 안정성처럼 사람이 끝까지 책임지는 층의 무게가 커진다고 봤기 때문입니다. 지금 AI와 협업해 제품을 만들면서 그 생각은 더 확고해졌습니다.

"품질이 나쁘다"로는 고칠 대상을 정할 수 없습니다. AI 생성 품질을 자동 게이트와 실측 분포 대조, 사람 판정 3층으로 나눠 판정 가능하게 만들었습니다.
```

참고: 현재 들어가 있는 소개는 `AI 제품을 만들고, 무엇을 왜 만들지도 정하는 4년차 백엔드 엔지니어입니다`로 시작하는 3문단(약 306자)이다. 이것을 지우고 위 문안으로 교체한다.

### 순서

1. `커넥트용` 탭 선택 → textarea 내용 교체 → 저장 버튼 클릭
2. `채용 서비스용` 탭 선택 → 동일하게 교체 → 저장
3. 페이지 새로고침(browser_reload) → 3~5초 대기
4. 검증: 본문에 `AI 제품을 만드는 일만 4년째` 포함 **그리고** `대체될` 미포함 **그리고** `4년차 백엔드 엔지니어입니다` 미포함
5. 두 탭 각각에 대해 4를 확인한다 (탭 전환 후 확인)

### 보고 형식

작업 종료 시 아래 형식으로 최종 보고한다:

```
[패키지 1 결과]
- 커넥트용: 교체 성공/실패 · reload 검증 통과/실패
- 채용 서비스용: 교체 성공/실패 · reload 검증 통과/실패
- 이상 징후: (있으면 서술, 없으면 "없음")
- 시도 중 실패한 조작: (있으면 무엇을 몇 회)
```

```
Backend Engineer로 위 시스템을 담당하면서 기업부설연구소장과 Tech Lead, PO를 병행하고 있습니다.
```

## 패키지 4 — 그룹바이 자기소개 교체

`https://groupby.kr/scouts/my-profile` 탭. **자기소개 필드 하나만 교체한다. 경력 설명은 절대 건드리지 않는다.**

### 진입

자기소개는 보기 모드에서 SPAN(읽기 전용)이다. 자기소개 영역 근처의 **편집(연필/수정) 버튼을 클릭**해 편집기를 연다. 편집기가 textarea면 execCommand 방식, contenteditable이면 전체 선택 후 insertText.

### 교체할 문안 (전문 — 목록까지 포함해 이 전체로 교체)


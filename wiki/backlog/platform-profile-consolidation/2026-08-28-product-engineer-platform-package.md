# Platform Profile Package — Product Engineer v1

## 적용 방향

- 첫인상은 `고객이 사용하는 AI 제품을 만들고 운영한 사람`으로 잡는다.
- FastAPI는 직함보다 제품을 안정적으로 출시·운영한 기술 근거로 사용한다.
- LinkedIn은 한눈에 읽히는 한 문단만 두고, 상세 기술 사례는 홈페이지로 연결한다.
- Wanted·Remember·Groupby는 경력 검토에 필요한 제품과 역할을 충분히 적는다.
- RocketPunch는 300자 안에서 제품 범위와 직접 구현 범위만 남긴다.
- 공식 경력 직무는 `Backend Engineer`로 유지하고 `Product Engineer`는 소개와 headline에서만 사용한다.
- 정확한 매출액, 고객 수, 내부 시스템명, `0→1`, `제품화`, 내부 검증 용어는 쓰지 않는다.


### 대표 경력

```text
- 유료 AI 콘텐츠 제품 — 기획·QA·마케팅 담당자와 고객 문제·기능 우선순위를 정하고 제품 운영을 리드. FastAPI 백엔드·독립 AI 서비스·Next.js 핵심 사용자 및 관리 흐름을 직접 구현
- 실시간 AI 상담·주문·재고 — WebSocket 상담 세션과 STT 이벤트 흐름의 주요 영역을 함께 맡고, 주문·재고 API와 RabbitMQ·TaskIQ 워커의 상태·재시도·실패 기록·재처리 기준을 설계·구현
- 병원 운영·예약 제품 — 여러 병원의 운영·예약을 지원하는 백엔드 구조와 관리·홈페이지 API 구축을 주도. 제품은 예약률 개선을 통해 고객사 매출 성과에 기여
- FastAPI 개발 기준 — 여러 직군이 코딩 에이전트로 구현에 참여해도 같은 방식으로 개발하도록 계층·DI·트랜잭션·비동기 세션·테스트 기준을 조직 표준 템플릿과 문서로 구축
```

### 기술 키워드 우선순위

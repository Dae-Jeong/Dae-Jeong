### 1.6 대표 성과 — **소개가 아니라 상세에 넣는다**

**정량은 소개·요약에서 빼고 경력 상세가 소유**하도록 바꿨다 ([dual-track-copy §0](dual-track-copy-draft.md)).

1. AI 도구로 급조된 생성 backend **전면 재구축** → QA 버그 재발률 **37% → 11%**, 재발 일평균 약 **94% 감소**
2. 월 수만 건 규모 요청을 **HTTP 5xx 0.3% 수준**으로 운영
3. **CES 2024 Best of Innovation 수상 제품**의 PM 메인 역할 · **특허 등록 1건** — 성과 수치가 아니라 검증된 사실 항목이라 요약에도 쓸 수 있다
4. Backend Engineer 합류 후 **기업부설연구소장·Tech Lead·PO 병행**
5. AI 생성 품질을 **자동 게이트·실측 분포·사람 판정 3층**으로 계량화
6. 스펙·이슈·릴리스 게이트를 **agent가 읽고 실행하는 workflow**로 설계·리드

#### 링크드인 자동화 제약 (2026-08-10 실측)

   | 자동화 | 필드 |
   | --- | --- |
   | ✅ 된다 | 헤드라인, 소개(About), 경력 설명(textarea), 날짜(combobox → `select`), 공개 URL |
   | ❌ 안 된다 | **직함·회사명(typeahead)**, **웹사이트 URL·링크 텍스트** |

   ❌ 항목은 `fill`이 화면에는 반영되지만 **저장 시 원래 값으로 복원**된다. 아래를 모두 시도해 전부 실패했다:

   | 시도 | 결과 |
   | --- | --- |
   | `fill(값)` | DOM은 바뀌나 저장 시 원래 값으로 복원 |
   | `fill('')` 후 `type` | React가 즉시 복원해 **기존 값 뒤에 덧붙음** |
   | `Meta+a` → `type` | 선택이 풀려 덧붙음 |
   | `Meta+a` → `Backspace` | 한 글자만 지워짐 |
   | `End` → `Shift+Home` → `Backspace` | 선택 안 됨, 값이 더 깨짐 |

   → **직함·회사명은 사용자가 직접 수정해야 한다.** 설명(textarea)·날짜(combobox)는 자동화 가능하다.

1. **CSP가 `browser_evaluate`를 차단한다.** 리멤버·그룹바이에서 쓴 native setter 방식을 못 쓴다. 스냅샷+클릭만 가능하고, 스냅샷 1회가 12,000자를 넘어 **작업당 컨텍스트 비용이 다른 플랫폼의 수 배**다.
2. **소개 필드에 문단 구분이 들어가지 않는다.** 문단마다 별도 textbox인 contenteditable 구조라 입력 시 개행이 공백으로 바뀐다. `Meta+a` 전체 선택도 듣지 않는다.
   → 4문장 한 문단으로 줄이면서 이 문제 자체가 사라졌다.

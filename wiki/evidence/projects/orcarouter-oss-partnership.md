# OrcaRouter OSS Developer Partnership Evidence

## Source Summary

- Source-backed (2026-09-05 확인): 사용자가 제공한 이메일 screenshot에서 OrcaRouter 측은 GitHub의 프로젝트를 보고 먼저 연락했으며, 해당 프로젝트에 `OrcaRouter`를 optional provider로 추가하는 OSS Developer Partner Program을 제안했다.
- Source-backed: 제안 조건은 referral link를 통해 가입한 사용자가 발생시키는 eligible paid inference spend의 5%를 월 단위로 정산하는 구조다. 현금 송금은 최소 $100부터 가능하고 API credit 선택지가 있으며, 별도 상한·최소 star·API 사용량 조건이 없다고 안내됐다.
- Source-backed: 승인 프로젝트는 `Built with OrcaRouter` directory에 등록될 수 있고, 기존 OpenAI-compatible API 구조라면 Base URL·API key·model ID를 추가하는 방식으로 연동할 수 있다고 안내됐다.
- User-confirmed (2026-09-05): 제안을 수락했다.
- Privacy boundary: raw email 본문·sender 식별 정보·개인 대화는 저장하지 않고 검증에 필요한 요약만 보존한다.

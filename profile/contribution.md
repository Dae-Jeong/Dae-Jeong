## Confidence Rules

- `High`: repo doc/code/Git/PR/운영 문서로 직접 확인됨.
- `Medium`: 구조는 확인됐지만 직접 기여 범위는 추가 확인 필요.
- `Low`: 기존 이력서나 기억 기반.
- `Unknown`: 확인되지 않음.

Public resume에는 `High`와 신중한 `Medium`만 사용한다.

root 아코디언 재사용 vs 카드 그리드 vs 넘버드 리스트

독립 /portfolio 목록 페이지는 넘버드 리스트로 결정. 좌측 mono 인덱스 + 케이스명·태그·한 줄 blurb + Role·Scope 메타 + 진입 화살표를 한 행에 담고, 행 전체가 상세로 가는 링크입니다.

root 아코디언과 달라야 하는 이유: root의 pf 아코디언은 같은 페이지 안에서 인라인으로 요약을 펼치는 게 목적입니다(홈에서 이탈 없이 미리보기). 그 패턴을 독립 목록 페이지에 그대로 쓰면 “펼침 → 요약 → 다시 상세 링크”라는 이중 내비게이션이 생겨, 이번 라운드에서 새로 만드는 상세 페이지의 존재 이유가 흐려집니다. 목록 페이지의 일은 5건을 한눈에 세로로 스캔하고 원하는 케이스로 바로 진입하는 것 — 넘버드 리스트가 이 두 동작에 가장 적은 구조입니다.

카드 그리드를 택하지 않은 이유: 카드 2×3 그리드는 시선을 좌↔우로 흩고, 5건(홀수)이라 마지막 칸이 비어 리듬이 깨집니다. 세로 리스트는 순번(01–05)이 곧 읽는 순서가 되어 mono의 하드 그리드·좌측 인덱스 규율과도 정합합니다.

택: 넘버드 리스트 / 반: root 아코디언 재사용 · 카드 그리드

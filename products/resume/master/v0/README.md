# Resume Master v0

[resume.html](resume.html)과 [resume.pdf](resume.pdf)은 이전 `14-resume-draft-v1` 산출물을 내용 변경 없이 재분류한 baseline이다.

- 활용: A4 구조, typography, density, print CSS inventory
- 상태: public-ready 아님
- 제한: section별 claim ID mapping, 최신 public-safety pass, v1 content contract 검증 전
- 승격 방식: 파일 이름만 바꾸지 않고 [content contract](../../content-contract.md)에 따라 v1을 새로 작성

이 디렉터리의 문구는 profile 또는 evidence의 canonical source가 아니다.

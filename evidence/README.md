# Evidence Hub

이 layer는 공개 문구보다 먼저 검증 사실과 허용 가능한 표현 강도를 소유한다.

## Migration State

기존 근거는 현재 `docs/resume/`에서 이관 중이다. 완료 후 기본 진입점은 다음과 같다.

| Need | Location |
| --- | --- |
| public claim registry | `claims/` |
| project evidence | `projects/` |
| broad research/audits | `audits/` |
| agent workflow evidence | `agent-workflow.md` |

정책은 [document routing](../rules/document-routing.md), 이후 추가될 `rules/evidence-policy.md`와 `rules/public-safety.md`를 따른다.
